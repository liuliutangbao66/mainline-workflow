# 项目启动任务卡：CSV 耗时统计

这是可复现教学案例的卡片。项目根目录为本次演示运行目录；不是对真实用户项目的授权。

## 1. 目标

交付一个离线 Python 脚本：读取 CSV 中的 duration_ms，统计有效记录数和平均耗时，输出被排除的记录 ID。本示例只有一个实现与验证阶段。

## 2. 背景与现状

输入为项目目录下 inputs/durations.csv，列为 id、duration_ms。五行分别为 10、20、空值、oops、30。尚未实现；不能把本文中的预期结果当作执行证据。活动文件、交接文件均在同一个本地演示目录。

## 3. 范围与约束

仅使用 Python 标准库。空值、非数字、非有限数、负数无效，不计入分母，需记录 ID。没有有效行时平均值为 null。不得修改原始 CSV，不联网、不付费、不对外发布。

读取 CSV → 过滤无效值 → 汇总 → 保存 JSON → 由主线按原始输入复算。任何验收项不通过都不接受交付；在新轮目录修复，保留旧轮。输入结构异常时停止，不静默猜测列名。
