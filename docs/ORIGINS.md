# 来源与边界

本套件由个人项目中的需求澄清、主线指导、阶段执行、证据审查和跨会话交接经验整理而来。通用版并未因此获得原项目所有实测结论。

目标澄清和访谈设计曾参考 [OpenAI Skills](https://github.com/openai/skills) 与 [Matt Pocock Skills](https://github.com/mattpocock/skills) 的方法；主线组织曾对照 [GSD Core](https://github.com/open-gsd/gsd-core)、[OpenSpec](https://github.com/Fission-AI/OpenSpec) 等公开工作流。此处是设计来源说明，不表示关联、背书或功能等价。

本仓库分发两个自行维护的入口及本地流程工具，采用 [MIT License](../LICENSE)。历史安装的旧技能、许可证归档、私人聊天和项目现场不在分发内容中。上述来源链接保留设计借鉴关系。
