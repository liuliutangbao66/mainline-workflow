# 主线管家 · Mainline

用两个 Skill，把项目想法整理成可验收任务，并保留跨会话接手所需的进度、证据和下一步。

**早期试用版。** 面向使用本地AI Agent推进多阶段项目的人。当前验证范围是Windows/Python工具运行与记录管理；完整采访和真实新会话接手仍需更多试用。

| 入口 | 负责什么 | 你提供什么 |
|---|---|---|
| `$task-card-refiner`（任务卡整理） | 澄清目标、按需追问、推敲方案、输出可复制启动卡 | 想法、背景、已有约束和验收要求，知道多少就写多少 |
| `$mainline`（主线管家） | 阶段规划、交付审查、按需验证、状态维护和交接 | 启动任务卡，或已有项目的入口 |

适合任务会经历多轮交付、返工或跨会话继续的项目。简单问答和一次性小修改可以直接做，不必创建流程记录。

[CSV耗时统计：提出想法 → 追问 → 启动卡 → 错误交付 → 返工 → 接受](examples/duration-summary/WALKTHROUGH.md)。附标准库复现脚本及完整任务卡，允许先运行再决定是否安装。

## 安装与开始

按 [安装及首次使用说明](docs/INSTALL.md) 复制两个完整技能目录。然后只需：

```text
$task-card-refiner
我想做……，目标是……，背景资料在……，约束是……。
```

回答关键问题后，把生成的启动卡复制给主线会话。信息已经清楚时会直接整理；不要求每次附长引导词。主线先核对实际目录和授权，再在相应范围内推进。

阶段执行可以由主线自己完成，也可以交给另一个获授权的执行者。后者通常仍需要用户转交简短任务入口并通知交付；本版没有后台唤醒、自动创建会话或跨机器通信。

## 会留下什么

初始化后在目标项目中创建 `.workflow/`，保存目标、版本化工具/协议、简短状态，以及按需产生的任务和证据。没有AGENTS.md时建立简短入口，已有文件则保留。初始化不运行项目业务程序。

主线检查证据后才可接受交付；报告存在不等于完成。返工生成新轮目录，保留旧记录。新会话先读当前入口，不需要递归加载全部历史。

## 验证与限制

- Python标准库运行，无模型API依赖；声明最低Python 3.10，本轮实际环境为Windows/Python 3.14.7。
- 测试及复现方法见 [验证说明](docs/VALIDATION.md)。角色标签不是身份认证；独立验证需要真实不同且获授权的验证者。
- 工具只校验选定文件和记录，不能证明全部业务正确，也不能强制所有Agent遵守指令。
- 目标与约束作为固定入口保存；重大变更需明确迁移。当前状态简述由Agent维护，没有硬性长度上限或自动上下文容量监测。
- 仅支持单机串行写入；跨OS、真实多会话及长期使用未完成系统验证。
