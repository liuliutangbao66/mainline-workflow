# 主线管家 · Mainline

两个配合使用的 Skill：**任务卡整理**帮你想清楚要做什么，**主线管家**负责分阶段推进、检查成果、记录进度。

**早期试用版。** 面向使用本地AI Agent推进多阶段项目的人。当前验证范围是Windows/Python工具运行与记录管理；完整采访和真实新会话接手仍需更多试用。

| Skill | 什么时候用 | 帮你做什么 |
|---|---|---|
| `$task-card-refiner`（任务卡整理） | 开始项目时，告诉它你的想法和背景 | 补问关键问题、讨论方案，整理成一份启动任务卡 |
| `$mainline`（主线管家） | 把任务卡交给它，开始推进项目 | 拆分阶段、检查成果、记录进度，方便换会话后继续 |

**使用顺序：提出想法 → 整理任务卡 → 交给主线管家 → 分阶段完成项目。**

适合任务会经历多轮交付、返工或跨会话继续的项目。简单问答和一次性小修改可以直接做，不必创建流程记录。

## 安装与开始

按 [安装及首次使用说明](docs/INSTALL.md) 复制两个完整技能目录。然后只需：

```text
$task-card-refiner
我想做……，目标是……，背景资料在……，约束是……。
```

回答关键问题后，把生成的任务卡复制到使用 `$mainline` 的会话。已经说清楚的内容不会重复问；你也不需要每次附上一段操作说明。主线管家会先确认项目位置和允许执行的范围，再开始推进。

主线管家可以自己完成阶段任务，也可以在你授权后交给其他 Agent。使用其他会话时，通常仍需要你转发任务并告知完成情况；本版不会自动创建或唤醒会话，也不会跨机器传递消息。

## 会留下什么

开始管理项目后，会创建 `.workflow/` 文件夹，保存目标、当前进度、任务、验证记录，以及该项目使用的流程规则和工具。没有 `AGENTS.md` 时会创建一份简短的阅读指引，已有文件则保留。创建这些记录不会运行项目业务程序。

主线管家检查成果和验证记录后，才会确认任务完成。需要返工时会保留旧记录。换会话后先读当前进度和必要材料，无需加载全部历史。

## 验证与限制

- Python标准库运行，无模型API依赖；声明最低Python 3.10，本轮实际环境为Windows/Python 3.14.7。
- 测试及复现方法见 [验证说明](docs/VALIDATION.md)。角色标签不是身份认证；独立验证需要真实不同且获授权的验证者。
- 工具只校验选定文件和记录，不能证明全部业务正确，也不能强制所有Agent遵守指令。
- 目标与约束作为固定入口保存；重大变更需明确迁移。当前状态简述由Agent维护，没有硬性长度上限或自动上下文容量监测。
- 仅支持单机串行写入；跨OS、真实多会话及长期使用未完成系统验证。
